##  ¿Qué trae FALauncher?
*  **5 Temas intercambiables en vivo:** Frutiger Aero, Aquatic, DORFic, Dark Aero y Minimalista.
*  **Ultraliviano:** Núcleo en Python puro (`minecraft-launcher-lib` + `pywebview`) sin consumir recursos de más.
*  **Listo para jugar:** Descarga versiones oficiales automáticamente, soporta modo offline y permite ajustar la RAM fácilmente.

---

## Cómo correrlo desde el código fuente

1. Cloná el repositorio:
   ```bash
   git clone https://github.com
   cd FALauncher
   ```
2. Instalá las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecutalo:
   ```bash
   python main.py
   ```
